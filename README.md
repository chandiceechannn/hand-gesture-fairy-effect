# hand-gesture-fairy-effect
Hand Gesture Fairy Effect 🧚 An interactive web project using MediaPipe hand tracking

## Demo
When a hand appears in front of the camera, magical fairy and power effects appear on the screen in real time.

## Technologies
- HTML
- JavaScript
- MediaPipe Hands
- Web Camera API

## How to Run

1. Download or clone this repository
2. Open the project folder
3. Open `index.html` in your browser
4. Allow camera access

## Features
- Real-time hand tracking
- Interactive fairy visual effect
- Power animation following the hand
- Gesture-based interaction
